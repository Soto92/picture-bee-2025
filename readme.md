# Rafinha Flash Cards

Made with love for my son **Rafael Soto**, to help him study English in school.  
A simple mobile-friendly flashcard app built with **HTML, CSS, and JavaScript**.

## Features

- Flashcards with images on the front and words on the back
- Tap a card to flip it
- "Next" button to cycle through the cards
- Optimized for mobile devices

## How to Use

1. Open `index.html` in a mobile browser
2. Tap the card to reveal the answer
3. Tap **Next** to go to the next card
